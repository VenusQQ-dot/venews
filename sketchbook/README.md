# 阿墨的十月速寫本 — 書架網站

單檔網站：`index.html`（HTML + CSS + JS 全在一檔，不需 build）。

## 使用

1. 把素材放進 `sketchbook/img/`（檔名如下，副檔名 jpg / png / webp 都可，會自動偵測）
2. 直接雙擊 `index.html` 開啟，或用任何靜態伺服器：`npx serve sketchbook`

| 檔名 | 用途 |
|---|---|
| `cover_2019` ~ `cover_2026` | 8 張封面（上方 1/3 留白，年份由網頁印上去） |
| `d2019_01` ~ `d2019_06` | 2019 內頁（粗黑線、交叉排線） |
| `d2025_01` ~ `d2025_06` | 2025 內頁（灰墨淡彩、小黑貓） |

找不到圖時會自動改用示意圖（右下角標 `PLACEHOLDER`），Console 會出現警告，方便檢查漏放的檔案。

## 要改內容，只改 `index.html` 裡的 `BOOKS` 陣列

- `pages`：每張畫的短標題（依序對應 `_01`、`_02`…）。**目前是依素材描述暫定的標題，請看過實際圖片後改成正確名稱。**
- `motto`：扉頁那一句話
- `base / pattern / patch / txt / band / symbol`：書背配色、花紋、幾何符號
- 其他年份要加內頁：在該年 `pages` 填標題，並放入 `dYYYY_01…` 圖檔即可

## 操作

| 動作 | 滑鼠 | 鍵盤 |
|---|---|---|
| 抽出書 | 點書背或年份按鈕 | Tab 到書背 + Enter |
| 翻開 | 點封面 | Enter |
| 翻頁 | 點右頁／左頁、上一頁／下一頁 | ← → |
| 回書架 | 「回書架」按鈕 | Esc |

支援 `prefers-reduced-motion`：系統開啟「減少動態效果」時，動畫改為直接切換。
